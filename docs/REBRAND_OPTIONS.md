**Problem:** “Aetheris” feels vague / hard to say / weak for social search.  
**Goal:** Name that works for **product URL + X + YouTube + optional Instagram/TikTok** before a public launch.  
**Constraint:** Educational longevity map — not a clinic, not a drug brand.

## Naming criteria (launch-soon)

1. **Sayable in 2 syllables** (or clear 3): works in YouTube titles and voiceovers  
2. **Handle-shaped:** short `@name` without forced underscores  
3. **Ownable metaphor:** body map / stack / orbit / atlas — not generic “AI health”  
4. **SEO-adjacent:** people might search “longevity stack” / “supplement map”  
5. **No overclaim:** avoid Cure / Immortal / Doctor / Clinic
